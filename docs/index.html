JustPractice

Track YouTube practice time. Build a local library. Tag videos with JLPT, CEFR, or custom levels.

Download extension ZIP View source on GitHub
Chrome extension GPL-3.0 Local practice storage

Features

Practice timer

Automatically counts playback for saved videos in a visible tab. Focus is also required by default. Daily goals and streaks on the dashboard.

Video library

Save videos from YouTube with difficulty tags (JLPT N5–N1, CEFR A1–C2, or your own custom list).

Full dashboard

Stats, heatmaps, Today path, achievements, and settings — open from the toolbar popup or extension options.

Private by default

Your practice record stays in chrome.storage.local in this profile. YouTube metadata and thumbnails still make network requests. Privacy and data flow.

Install in Chrome (developer mode)

Chrome does not support one-click install outside the Web Store. Follow these steps to load the extension from a release zip:

  1. Download the ready-to-load justpractice.zip. Do not choose GitHub’s automatic “Source code” archives; those require a build.
  2. Extract the zip to a folder (e.g. justpractice/). You should see manifest.json at the top level.
  3. Open chrome://extensions.
  4. Enable Developer mode (top right).
  5. Click Load unpacked and select the extracted folder (not the zip file).
Updates: Export a backup first. Replace the files in your existing unpacked folder and click Reload in chrome://extensions. A new folder/profile can be a separate installation; keep your backup for restore.
Build from source instead 
git clone https://github.com/thepoppfish/JustPractice.git
cd JustPractice
npm ci
npm run build

Then load the dist/ folder as an unpacked extension.

Quick usage

  • Toolbar popup for today’s progress; open the dashboard for full stats.
  • On YouTube watch or Shorts: use the floating panel to save a video and choose a level. Saved videos count automatically while playing in a visible tab; there is no separate practice switch.
  • Right-click video links → JustPractice → pick a level.
  • Pause playback or hide the tab to stop counting. By default, the YouTube page must also have focus. Turn off the focus setting to count a visible video in another window; hidden tabs never count.
  • Settings: level framework (JLPT / CEFR / Custom), UI language (EN, FR, JA, HE, ES, DE).

Privacy: No JustPractice account or backend. Practice data is stored locally under jpPractice; YouTube requests still occur. Read storage, requests, permissions and backup guidance.
