JustPractice

Track YouTube practice time. Build a local library. Tag videos with JLPT, CEFR, or custom levels.

Download latest release View source on GitHub
Chrome extension GPL-3.0 Local-only data

Features

Practice timer

Counts watch time while YouTube plays (visible, focused tab). Daily goals and streaks on the dashboard.

Video library

Save videos from YouTube with difficulty tags (JLPT N5–N1, CEFR A1–C2, or your own custom list).

Full dashboard

Stats, heatmaps, Today path, achievements, and settings — open from the toolbar popup or extension options.

Private by default

All data stays in chrome.storage.local on your device. Export or import a JSON backup anytime.

Install in Chrome (developer mode)

Chrome does not support one-click install outside the Web Store. Follow these steps to load the extension from a release zip:

  1. Download the latest justpractice-*.zip from Releases.
  2. Extract the zip to a folder (e.g. justpractice-1.0.0/). You should see manifest.json at the top level.
  3. Open chrome://extensions.
  4. Enable Developer mode (top right).
  5. Click Load unpacked and select the extracted folder (not the zip file).
Updates: Download a new release zip and load the new folder, or replace the files in your folder and click Reload on the extension card in chrome://extensions.
Build from source instead 
git clone https://github.com/thepoppfish/JustPractice.git
cd JustPractice
npm install
npm run build

Then load the dist/ folder as an unpacked extension.

Quick usage

  • Toolbar popup for today’s progress; open the dashboard for full stats.
  • On YouTube watch: floating panel — save to library, set level, practice timer, mini calendar.
  • Right-click video links → JustPractice → pick a level.
  • Settings: level framework (JLPT / CEFR / Custom), UI language (EN, FR, JA, HE, ES, DE).

Privacy: No accounts, no server. Practice data is stored under the key jpPractice in Chrome local storage on your device.
