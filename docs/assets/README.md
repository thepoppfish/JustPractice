# Product screenshot provenance

The `candidate-*.png` images are actual installed Chromium screenshots from the
source candidate 1.0.3 on 9 November 2026, including the open polish PR stack
through PR #7 (`3a1da0330c2cb52f971f3dc6af1e8e585608d362`). They are not a claim
about the current public release. Only synthetic video IDs/titles, practice
records and thumbnail placeholders were used; the panel uses a minimal YouTube
fixture rather than a streaming account.

- `candidate-statistics.png`: English dashboard, 1440×900, 20 minutes today,
  three saved videos with one completed.
- `candidate-library.png`: English dashboard, 1440×900, five saved videos with
  one completed, and mixed English/French/Japanese/Hebrew test titles.
- `candidate-watch-panel.png`: English watch-panel element crop, 300×738.
- `candidate-hebrew-statistics.png`: Hebrew dashboard, 1440×900, native RTL
  navigation and mixed-direction practice summaries.

These are different representative synthetic states, not one synchronized user
record. Original screenshots, native zoom pixels, raw accessibility results and
synthetic profiles are retained locally under `output/playwright/` and excluded
from the runtime ZIP. Older `screenshot-*.png` files are historical previews and
are no longer used in the current README/site.
