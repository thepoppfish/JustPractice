- Validate backup identity, supported schema, nested practice data, and size before confirmation. Preview saved videos, completed videos, and practice minutes.
- Keep a session recovery copy until restore succeeds. Recover interrupted restores before the next storage operation, and roll back failed replacements without clearing the original data first.
- Keep the watch panel’s drag bar visible in short browser windows. Scroll its contents and constrain default and saved positions after resizing or content changes.
- Serialize background storage updates so concurrent practice ticks and delayed metadata cannot overwrite newer progress, edits, or deletions.

Install `justpractice.zip` or `justpractice-1.0.1.zip`, extract it, and load the extracted folder from `chrome://extensions` with Developer mode enabled. Automatic GitHub source archives require building first.

Back up existing data before updating. Keep the same unpacked-extension folder and use Reload in Chrome to preserve its extension identity and local data.
