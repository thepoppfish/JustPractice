# JustPractice 1.0.3

**Released 10 November 2026.** [Download the installable ZIP](https://github.com/thepoppfish/JustPractice/releases/download/1.0.3/justpractice.zip)
or open [the GitHub release](https://github.com/thepoppfish/JustPractice/releases/tag/1.0.3).
These notes describe the merged polish work. See [the review tracker](../polish/index.html)
for verification evidence. The final normal-Chrome repeat passed sustained
playback at 94.0% media advancement (above 85%), ten-minute practice tracking,
pause and exact reload persistence. Earlier incomplete runs remain documented.
The maintainer
explicitly skipped manual screen-reader verification; no reader pass is claimed.

Extract the runtime ZIP, then use **Load unpacked** in Chrome's extension manager
on the folder containing `manifest.json`. GitHub's automatic source archives
require a build. For an existing installation, export a backup first, replace
files in the same unpacked-extension folder and use **Reload**. Keep the folder
path to preserve the extension ID; uninstalling removes that installation's local data.
