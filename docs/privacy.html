Privacy and data flow

Your practice record stays in this Chrome profile. Some features still make requests to YouTube.

Reviewed 9 November 2026 for the source candidate 1.0.3. Open polish PRs can be ahead of the public download. Older builds also request alarms only to cancel a retired reminder; this candidate removes that permission and the obsolete cleanup calls.

What is stored on your device?

chrome.storage.local, primarily the jpPractice record, contains saved video IDs, titles, channels, levels, saved/completed dates and durations; daily and per-video practice totals; playback positions; goals, XP and roadmap state; language/display preferences, panel position, and optional display name and custom messages.

Temporary chrome.storage.session records support restore recovery and library Undo. Dashboard navigation uses page session storage; unsaved form drafts live in page memory. These temporary records are not permanent backups. The extension does not use Chrome Sync to synchronize practice data between devices.

There is no JustPractice account, application server or analytics endpoint in this source. Local storage is not a promise of encrypted storage: protect your browser profile and exported JSON files as you would other personal files.

When does the browser contact other services?

YouTube metadata — www.youtube.com
Saving a video can request its title/channel through the oEmbed endpoint. Missing durations can be fetched from its watch page, including a rate-limited dashboard backfill. The requested video ID/URL identifies the video. Duration fetches explicitly omit credentials. Practice totals, goals, custom messages and your display name are not included in these metadata requests.
Thumbnail images — i.ytimg.com
Library cards and the onboarding tutorial preview request images whose URLs contain the video ID. Viewing a saved library can therefore contact YouTube's image CDN even without playing a video.
YouTube viewing and tutorial
Opening a saved video or the onboarding tutorial visits YouTube normally. The public project website embeds a YouTube tutorial; loading/playing it can contact YouTube and its playback services. Their ordinary network, cookie and account behavior is controlled by your browser and YouTube, independently of local practice storage.
Project hosting and downloads — GitHub / GitHub Pages
Visiting the project website or repository and downloading a release contacts GitHub's hosting/download infrastructure. The static site has no project-added analytics script. It does not read your extension's practice record.

External services receive normal network information such as your IP address and request headers. “Local practice data” describes storage, not an offline guarantee or a claim that no third party receives requests. Chrome and YouTube may make their own requests beyond the extension's code.

Why these Chrome permissions?

storage
Keep the practice record and settings, plus temporary recovery/Undo records.
contextMenus
Add JustPractice save/level choices to right-click menus on YouTube pages, links and videos.
scripting
Inject the packaged watch-panel script into an already-open YouTube tab when its content script is missing, so settings/actions can reach that tab.
YouTube host access
Access is limited to HTTPS www.youtube.com, youtube.com and m.youtube.com pages. This supports the watch panel, playback observation, relevant tab messaging and metadata requests. It is not access to every website. Recognizing a youtu.be link does not grant that host permission.

The candidate does not request alarms, history, cookies, downloads, notifications or unlimitedStorage permissions. Export uses a browser file download initiated from the extension page.

Back up, restore or remove your record

Use Dashboard → Settings → Your data → Export JSON before uninstalling, changing profiles or replacing an unpacked installation. Keep the downloaded file somewhere safe. It contains readable local data and can reveal your saved-video choices and practice history; avoid attaching it to public bug reports.

Restore accepts recognized JustPractice exports up to 8 MB, validates their contents and previews counts before confirmation. The temporary recovery journal protects a failed/interrupted replacement while the browser session survives; it is not a durable backup across browser restart or uninstall.

Clear requires confirmation and resets the local JustPractice record and pending library Undo. Removing a library video retains its historical practice totals. Uninstalling removes Chrome's local extension storage. Neither Clear nor uninstall deletes JSON files you downloaded, your YouTube history, or information already held by external services.
